# Blazor Table

The Blazor Bootstrap `Table` component renders a read-only Bootstrap 5.3 table from a list, one row per item, with columns declared as `TableColumn` children. It covers every variation on the Bootstrap 5.3 tables page: color variants, striped rows and columns, hover, borders, small tables, group dividers, vertical alignment, head colors, captions, responsive scrolling, and nesting. Use it for invoices, reports, plan comparisons, and other small tables.

<CarbonAd />

## Before you start

- **Table or Grid.** `Table` is the lightweight, read-only sibling of [`Grid`](/components/grid). Use `Grid` when you need paging, sorting, filtering, selection, a data provider, or editing. The two share parameter names wherever they do the same thing, such as `RowClass`, `ColumnClass`, `EmptyText`, `RowKeySelector`, and `IsVisible`.
- **Columns.** Each `TableColumn` renders its cell from its content, with the row item as `@context`. Columns take `TItem` from the table, so you do not have to repeat it.
- **States.** While `Data` is `null`, the table shows placeholder rows (or `LoadingTemplate`); when it is empty, it shows one row with `EmptyText` or `EmptyDataTemplate`. Footers are hidden in both states.
- **Footers.** Set `FooterText` or `FooterTemplate` on columns for one footer row. For a label that spans columns, or several footer rows, write the rows yourself in the table's `FooterTemplate`.
- **Row keys.** Set `RowKeySelector` to keep rows when the same records come back as new instances. Keys must be unique. Without it, rows are matched by position, so a list with equal items works as it is.
- **Row index.** A column's content receives the row item only. To show a rank or row number, pair each item with its index: `Data="items.Select((item, index) => (item, index))"`.
- **No JavaScript.** Every option maps to a Bootstrap class, so the table follows the light and dark themes.
- **Name clashes.** If your app has its own `Table`, `TableColumn`, or `TableColor` type, write the full name, such as `<BlazorBootstrap.Table TItem="Invoice">`.
- **Clipped popups.** Bootstrap's responsive wrapper sets `overflow-y: hidden`, so a dropdown or popover inside a responsive table's cell can be cut off. Leave `Responsive` off for such tables, or open the menu outside the table.

## Accessibility

- Header cells render as `<th scope="col">`. Set `IsRowHeader` on the column that names each row; its cells render as `<th scope="row">`.
- Set `Caption` (or `CaptionTemplate`) to name the table. Use `VisuallyHiddenCaption` when a visible heading already names it.
- A responsive table's scrolling wrapper takes keyboard focus, so keyboard users can scroll it with the arrow keys, and screen readers announce it as a region named by the caption.
- Row and cell colors must never be the only way the meaning is shown: say it in a cell's text too.
- Don't give a cell a color on an active row. In dark mode, Bootstrap's active state sets a light text color for the whole row, which falls below 4.5:1 on a colored cell.
- The empty-state row carries no `role="alert"`, so screen readers do not announce every empty table when a page loads.

## Examples

### Basic usage

A table with a caption, a row header, and a right-aligned amount column. Cells can hold other components, such as a badge.

```cshtml {} showLineNumbers
<Table TItem="Invoice" Data="invoices" Caption="Last four invoices">
    <TableColumn HeaderText="Invoice" IsRowHeader="true">@context.Number</TableColumn>
    <TableColumn HeaderText="Customer">@context.Customer</TableColumn>
    <TableColumn HeaderText="Amount" TextAlignment="Alignment.End" HeaderTextAlignment="Alignment.End">@context.Amount.ToString("C")</TableColumn>
    <TableColumn HeaderText="Status">
        <Badge Color="@(context.IsPaid ? BadgeColor.Success : BadgeColor.Warning)">@(context.IsPaid ? "Paid" : "Due")</Badge>
    </TableColumn>
</Table>
```

[See demo here](https://demos.blazorbootstrap.com/demos/table#basic-usage)

### Loading and empty states

```cshtml {} showLineNumbers
<Table TItem="Order" Data="orders" EmptyText="No orders yet.">
    <TableColumn HeaderText="Order" IsRowHeader="true">@context.Number</TableColumn>
    <TableColumn HeaderText="Items" TextAlignment="Alignment.End" FooterText="@orders?.Sum(o => o.Items).ToString()">@context.Items</TableColumn>
</Table>

@code {
    private List<Order>? orders; // null shows placeholder rows until the data arrives
}
```

[See demo here](https://demos.blazorbootstrap.com/demos/table#loading-and-empty-states)

### Footer template

```cshtml {} showLineNumbers
<Table TItem="InvoiceLine" Data="lines">
    <ChildContent>
        <TableColumn HeaderText="Item" IsRowHeader="true">@context.Item</TableColumn>
        <TableColumn HeaderText="Hours" TextAlignment="Alignment.End">@context.Hours</TableColumn>
        <TableColumn HeaderText="Amount" TextAlignment="Alignment.End">@context.Amount.ToString("C")</TableColumn>
    </ChildContent>
    <FooterTemplate>
        <tr>
            <th scope="row" colspan="2">Total</th>
            <td class="text-end">@lines.Sum(l => l.Amount).ToString("C")</td>
        </tr>
    </FooterTemplate>
</Table>
```
