# Blazor List Group

The Blazor Bootstrap `ListGroup` component follows the [Bootstrap 5.3 list group](https://getbootstrap.com/docs/5.3/components/list-group/). It shows a list of items, links, or buttons; lets users select one item, several items, or check items with checkboxes or radios; or turns the items into tabs that switch content panes.

<CarbonAd />

## Before you start

- **Two modes.** Add `ListGroupItem` children (static mode), or set `Data` with `TextField` or `ItemTemplate` (data-bound mode).
- **`TItem` is the type of the item values.** Razor infers it from `Data` or a selection binding; a static list without either still sets it, for example `TItem="string"`.
- **`Flush` and `Horizontal` do not combine.** `Flush` is ignored while `Horizontal` is set.
- **Value types and single selection.** `SelectedItem` starts at the type's default, so with `TItem="int"` an item whose value is `0` shows as selected. Use a nullable type, such as `int?`, when nothing should be selected at first.
- **Tab mode** uses the Bootstrap JavaScript bundle the app already loads.
- **Static lists of links or buttons.** A static list starts as a `ul` and becomes a `div` when its first `Href` or `OnClick` item registers, which re-creates the items (and any components inside them) once. Set `OnItemClick` on the group, or use data-bound mode, to start as a `div`.
- **Tab panes that come and go.** A pane added later (for example with `@if`) takes its place in markup order and is not shown until chosen. When the shown pane is removed, the first enabled tab is shown (`OnShowing` and `OnShown` fire for it).
- **Tab stop before the page is interactive.** Until the list's script runs (for example in prerendered HTML), the Tab key reaches the first selected option, or the first enabled one. A static list decides from the bound value and its items in the order they register, which is markup order for direct children; a data-bound list decides from `Data`. A static list whose `SelectedItem` equals the type's default (for example `0` for `int`) counts as having no selection here. Once the script runs, the tab stop follows focus and selection.
- **Name selectable lists and tab lists.** A listbox (`Single`, `Multiple`) and a tab list need `AriaLabel` or `aria-labelledby`; without one, screen readers announce them without a name.

## Accessibility

- A plain list is a `ul` (or an `ol` when `Numbered`); a list of links or buttons is a `div`, as in Bootstrap. The active item is marked `aria-current="true"`.
- A disabled link has no `href`, is marked `aria-disabled="true"`, and does not navigate. A disabled button uses the native `disabled` attribute.
- With `SelectionMode` `Single` or `Multiple`, the list is a `listbox` (`aria-multiselectable="true"` for `Multiple`) and items are `option`s with `aria-selected`. Tab moves into the list, the arrow keys, Home, and End move between items, and Space or Enter selects (in `Multiple`, it toggles; in `Single`, choosing another item replaces the selection, as in the WAI-ARIA single-select listbox). A check mark shows selected items, so selection is not shown by color alone. Give the list an accessible name with `AriaLabel` or `aria-labelledby`.
- With `Checkbox` or `Radio`, each item has a real input and label. Set `AriaLabel` on an item that has no visible text.
- In tab mode the list is a `tablist`, items are `tab`s, and panes are `tabpanel`s linked with `aria-controls` and `aria-labelledby`. The arrow keys move between tabs.
- In an `EditForm`, an invalid selectable list gets `aria-invalid="true"`.

## ListGroup methods

| Name | Description | Added Version |
|:--|:--|:--|
| ShowTabAsync(string name) | Shows the tab pane with the given name. Applies in tab mode. | 4.1.0 |

## ListGroup events

| Name | Description | Added Version |
|:--|:--|:--|
| OnHidden | This event fires after a tab pane is hidden. Applies in tab mode. | 4.1.0 |
| OnHiding | This event fires when a tab pane starts to hide. Applies in tab mode. | 4.1.0 |
| OnItemClick | This event fires when the user clicks an item. Items become buttons when it is set. | 4.1.0 |
| OnShowing | This event fires when a tab pane starts to show. Applies in tab mode. | 4.1.0 |
| OnShown | This event fires after a tab pane is shown. Applies in tab mode. | 4.1.0 |
| SelectedItemChanged | This event fires when the user selects a different item. | 4.1.0 |
| SelectedItemsChanged | This event fires when the user selects or deselects an item. The new set keeps the existing order, with a newly selected item added at the end. | 4.1.0 |

The tab events receive a `ListGroupTabEventArgs` with `ActiveTabName` and `PreviousTabName`.

## Examples

### Basic usage

```cshtml {} showLineNumbers
<ListGroup TItem="string">
    <ListGroupItem Active="true">An active item</ListGroupItem>
    <ListGroupItem>A second item</ListGroupItem>
    <ListGroupItem>A third item</ListGroupItem>
</ListGroup>
```

[See demo here](https://demos.blazorbootstrap.com/list-group#basic-usage)

### Links and buttons

```cshtml {} showLineNumbers
<ListGroup TItem="string">
    <ListGroupItem Href="/inbox" Active="true">Inbox</ListGroupItem>
    <ListGroupItem Href="/archive">Archive</ListGroupItem>
    <ListGroupItem Href="/trash" Disabled="true">Trash</ListGroupItem>
</ListGroup>

<ListGroup TItem="string">
    <ListGroupItem OnClick="Archive">Archive</ListGroupItem>
    <ListGroupItem OnClick="Delete" Disabled="true">Delete</ListGroupItem>
</ListGroup>
```

[See demo here](https://demos.blazorbootstrap.com/list-group#links-and-buttons)

### Flush, numbered, horizontal, and colors

```cshtml {} showLineNumbers
<ListGroup TItem="string" Flush="true">...</ListGroup>
<ListGroup TItem="string" Numbered="true">...</ListGroup>
<ListGroup TItem="string" Horizontal="true" HorizontalBreakpoint="ListGroupHorizontalBreakpoint.Medium">...</ListGroup>

<ListGroup TItem="string">
    <ListGroupItem Color="ListGroupColor.Success">Payment received</ListGroupItem>
    <ListGroupItem Color="ListGroupColor.Danger">Payment failed</ListGroupItem>
</ListGroup>
```

[See demo here](https://demos.blazorbootstrap.com/list-group#horizontal)

### Checkboxes and radios

```cshtml {1,7} showLineNumbers
<ListGroup @bind-SelectedItems="topics" SelectionMode="ListGroupSelectionMode.Checkbox" AriaLabel="Notify me about">
    <ListGroupItem Value="@("mentions")">Mentions</ListGroupItem>
    <ListGroupItem Value="@("replies")">Replies to my posts</ListGroupItem>
    <ListGroupItem Value="@("digest")">Weekly digest</ListGroupItem>
</ListGroup>

<ListGroup @bind-SelectedItem="plan" SelectionMode="ListGroupSelectionMode.Radio" StretchedLink="true" AriaLabel="Plan">
    <ListGroupItem Value="@("free")">Free</ListGroupItem>
    <ListGroupItem Value="@("pro")">Pro</ListGroupItem>
</ListGroup>
```

```cs {} showLineNumbers
@code {
    private IEnumerable<string> topics = new[] { "mentions" };
    private string plan = "pro";
}
```

[See demo here](https://demos.blazorbootstrap.com/list-group#checkboxes-and-radios)

### Single and multiple selection

```cshtml {1} showLineNumbers
<ListGroup @bind-SelectedItem="conversation" SelectionMode="ListGroupSelectionMode.Single" AriaLabel="Conversations">
    <ListGroupItem Value="@("Release planning")">Release planning</ListGroupItem>
    <ListGroupItem Value="@("Support rota")">Support rota</ListGroupItem>
</ListGroup>
```

Use `SelectionMode="ListGroupSelectionMode.Multiple"` with `@bind-SelectedItems` to select several items.

[See demo here](https://demos.blazorbootstrap.com/list-group#single-selection)

### Data binding and templates

```cshtml {1-5} showLineNumbers
<ListGroup TItem="Country" Data="countries" SelectionMode="ListGroupSelectionMode.Checkbox" @bind-SelectedItems="selected" AriaLabel="Countries">
    <ItemTemplate Context="country">
        @country.Name <Badge Color="BadgeColor.Secondary">@country.Code</Badge>
    </ItemTemplate>
</ListGroup>
```

```cs {} showLineNumbers
@code {
    private readonly Country[] countries = { new("India", "IN"), new("Japan", "JP") };
    private IEnumerable<Country> selected = Array.Empty<Country>();

    public record Country(string Name, string Code);
}
```

Without a template, set `TextField="@(c => c.Name)"`. Set `DisabledSelector` to disable data-bound items, and `OnItemClick` to make them buttons.

[See demo here](https://demos.blazorbootstrap.com/list-group#templates)

### Tabs

```cshtml {1-3} showLineNumbers
<ListGroup TItem="string" TabMode="true" AriaLabel="Settings sections" OnShown="OnShown">
    <ListGroupTabPane Name="profile" Title="Profile">Your name, photo, and contact details.</ListGroupTabPane>
    <ListGroupTabPane Name="billing" Title="Billing">Invoices, payment method, and plan.</ListGroupTabPane>
    <ListGroupTabPane Name="danger" Title="Danger zone" Disabled="true">...</ListGroupTabPane>
</ListGroup>
```

```cs {} showLineNumbers
@code {
    private void OnShown(ListGroupTabEventArgs e) => Console.WriteLine($"Showing {e.ActiveTabName}");
}
```

[See demo here](https://demos.blazorbootstrap.com/list-group#tabs)
