# Blazor Avatar

The Blazor Bootstrap Avatar component shows a person or entity as an image, initials, or an icon, with an optional presence status. AvatarGroup stacks several avatars and adds a "+N" button for the ones it hides.

<CarbonAd />

## Before you start

- **Icons:** icon avatars, including the default person icon, use Bootstrap Icons. Reference the Bootstrap Icons stylesheet in your app; the package does not include it.
- **Broken images:** when an image fails to load, the avatar falls back to initials, then an icon. The fallback runs once the component is interactive (Interactive Server, WebAssembly, or Auto). On a static server-rendered page, a broken image stays as rendered.
- **Image URLs:** `ImageUrl` is used as the image source unchanged, so the browser requests it directly. Only pass URLs you trust.
- **No JavaScript:** Avatar and AvatarGroup use no JavaScript interop.

## CSS variables

| Name | Default | Description |
|:--|:--|:--|
| `--bb-avatar-size` | set by `Size` | Width and height of the avatar. Initials, icons, and the status dot scale with it. Set it on an `Avatar`, or on an `AvatarGroup` for the whole group. |
| `--bb-avatar-group-overlap` | 25% of the avatar size | How far each avatar in a group overlaps the previous one. |

## Accessibility

- An image avatar uses `Name` as its alternative text; an initials or icon avatar is announced as an image named `Name`.
- With a status, the status text is added to the name, for example "Jane Doe, Online". Translate it with `OnlineText`, `AwayText`, `BusyText`, and `OfflineText`.
- An avatar without `Name` is decorative and hidden from screen readers. Add `aria-label` or `aria-labelledby` to name it yourself, or `aria-hidden="true"` to hide a named avatar shown next to the same visible name.
- `AvatarGroup` has `role="group"`. Name it with `aria-label` or `aria-labelledby`.
- The "+N" button shows the hidden names in a tooltip on hover, and opens or closes a list of them on click, tap, <kbd>Enter</kbd>, or <kbd>Space</kbd>.

## Examples

### Image, initials, and icon

Set `Name` for initials and the accessible name, and `ImageUrl` for a photo. Without an image, the avatar shows initials, then the icon from `IconName`, then a person icon.

```cshtml {} showLineNumbers
<Avatar ImageUrl="images/jane.png" Name="Jane Doe" />
<Avatar Name="Jane Doe" />
<Avatar Name="Rahul" Color="AvatarColor.Primary" />
<Avatar Name="María José García" Initials="MJ" Color="AvatarColor.Success" />
<Avatar IconName="IconName.Building" Color="AvatarColor.Info" aria-label="Contoso Ltd" />
<Avatar />
```

Initials use the first letter of the first and last words of `Name`; a single word gives one letter.

### Broken image fallback

When the image fails to load, the avatar shows the next source. Changing `ImageUrl` tries the new image again.

```cshtml {} showLineNumbers
<Avatar ImageUrl="images/missing-photo.png" Name="Jane Doe" />
<Avatar ImageUrl="images/missing-photo.png" IconName="IconName.Robot" />
```

### Group with overflow

`AvatarGroup` shows at most `Max` avatars, followed by a "+N" button for the rest.

```cshtml {} showLineNumbers
<AvatarGroup Max="3" aria-label="Project team">
    @foreach (var person in people)
    {
        <Avatar @key="person" Name="@person.Name" ImageUrl="@person.ImageUrl" />
    }
</AvatarGroup>
```

The visible avatars are the first `Max` in the order they were added. Adding and removing avatars at the end keeps that order; an avatar inserted in the middle of the list after the first render is placed last.

### Group size, shape, and overlap

```cshtml {} showLineNumbers
<AvatarGroup Size="AvatarSize.Large" Shape="AvatarShape.Rounded" Max="3" aria-label="Reviewers">
    @foreach (var name in names)
    {
        <Avatar Name="@name" />
    }
</AvatarGroup>

<AvatarGroup Max="4" Style="--bb-avatar-group-overlap: .25rem;" aria-label="Watchers">
    @foreach (var name in names)
    {
        <Avatar Name="@name" />
    }
</AvatarGroup>
```

The overlap mirrors automatically in right-to-left layouts.

### Inside a grid, dropdown, or tooltip

```cshtml {} showLineNumbers
<GridColumn TItem="Employee" HeaderText="Employee" PropertyName="Name">
    <div class="d-flex align-items-center gap-2">
        <Avatar Name="@context.Name" ImageUrl="@context.ImageUrl" Size="AvatarSize.Small" />
        <span>@context.Name</span>
    </div>
</GridColumn>

<Dropdown Color="DropdownColor.Light">
    <DropdownToggleButton>
        <Avatar Name="Jane Doe" Status="AvatarStatus.Online" Size="AvatarSize.Small" class="me-2" /> Jane Doe
    </DropdownToggleButton>
    <DropdownMenu>
        <DropdownItem To="#" Type="DropdownItemType.Link">Profile</DropdownItem>
    </DropdownMenu>
</Dropdown>

<Tooltip Title="Kwame Mensah, Busy">
    <Avatar Name="Kwame Mensah" Status="AvatarStatus.Busy" />
</Tooltip>
```
