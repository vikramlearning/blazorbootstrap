# Blazor Navbar

The Blazor Bootstrap `Navbar` component is a responsive navigation header that follows the [Bootstrap 5.3 navbar](https://getbootstrap.com/docs/5.3/components/navbar/). It holds a brand, navigation links, dropdowns, forms, and text, and collapses them behind a toggler, or into an offcanvas panel, below a breakpoint. The collapse, offcanvas, and dropdowns use the Bootstrap JavaScript bundle the app already loads.

<CarbonAd />

## Components

- `Navbar`: the navigation landmark. Put the brand in its `Brand` slot and the menu in `ChildContent`.
- `NavbarBrand`: the brand, as a link, plain text, an image, or an image and text.
- `NavbarNav`: the navigation list, holding `NavbarItem` and `NavbarDropdown` components.
- `NavbarItem`: a link. It is active, with `aria-current="page"`, when its `Href` matches the current URL.
- `NavbarDropdown`: a dropdown holding the existing `DropdownItem`, `DropdownHeader`, and `DropdownDivider` components.
- `NavbarText`: text colored and aligned for the navbar.

## Behavior

- The collapsed menu closes by itself after a navigation.
- `ShowAsync`, `HideAsync`, and `ToggleAsync` control the collapsed menu from code. They do nothing while the navbar is expanded.
- Beside a `Sidebar`, `Sidebar2`, or `BlazorBootstrapLayout`, the navbar uses Bootstrap's own sticky (1020) and fixed (1030) z-index.
- Animations follow Bootstrap, which turns them off when the user prefers reduced motion.

## Accessibility

- Set `AriaLabel` when the page has more than one navigation landmark.
- The toggler has `aria-controls`, `aria-expanded`, and a label set by `TogglerAriaLabel` (default "Toggle navigation").
- Dropdown toggles are buttons with `aria-expanded`, and work by keyboard: Enter or Space opens the menu, the arrow keys move through it, and Escape closes it.
- Give a search form `role="search"`, and give each input an `aria-label`.
- With `ExternalCollapseId`, focus moves into the external content when it opens.

## Navbar methods

| Name | Description | Added Version |
|:--|:--|:--|
| HideAsync() | Hides the collapsed menu. Does nothing when the navbar is expanded or the menu is already hidden. | 4.1.0 |
| ShowAsync() | Shows the collapsed menu. | 4.1.0 |
| ToggleAsync() | Shows the collapsed menu if it is hidden, or hides it if it is shown. | 4.1.0 |

## Examples

### Basic usage

```cshtml {1-23} showLineNumbers
<Navbar BackgroundColor="BackgroundColor.BodyTertiary" AriaLabel="Main navigation">
    <Brand>
        <NavbarBrand Href="/">Navbar</NavbarBrand>
    </Brand>
    <ChildContent>
        <NavbarNav Class="me-auto mb-2 mb-lg-0">
            <NavbarItem Href="/" Match="NavLinkMatch.All">Home</NavbarItem>
            <NavbarItem Href="/pricing">Pricing</NavbarItem>
            <NavbarDropdown Text="Products">
                <DropdownItem Type="DropdownItemType.Link" To="/products/new">New arrivals</DropdownItem>
                <DropdownItem Type="DropdownItemType.Link" To="/products/sale">On sale</DropdownItem>
                <DropdownDivider />
                <DropdownItem Type="DropdownItemType.Link" To="/products">All products</DropdownItem>
            </NavbarDropdown>
            <NavbarItem Disabled="true">Disabled</NavbarItem>
        </NavbarNav>
        <form class="d-flex" role="search" @onsubmit="Search">
            <TextInput @bind-Value="query" Class="me-2" Placeholder="Search" aria-label="Search" />
            <Button Type="ButtonType.Submit" Color="ButtonColor.Success" Outline="true">Search</Button>
        </form>
    </ChildContent>
</Navbar>
```

```cs {} showLineNumbers
@code {
    private string? query;

    private void Search() { }
}
```

[See demo here](https://demos.blazorbootstrap.com/navbar#basic-usage)

### Brand

```cshtml {} showLineNumbers
<Navbar BackgroundColor="BackgroundColor.BodyTertiary">
    <Brand>
        <NavbarBrand Href="/" ImageSrc="images/logo.svg" ImageAlt="" ImageWidth="30" ImageHeight="24">Blazor Bootstrap</NavbarBrand>
    </Brand>
</Navbar>
```

Leave `Href` unset for a plain-text brand. Set `ImageAlt` to the brand name when the image is shown without text.

[See demo here](https://demos.blazorbootstrap.com/navbar#brand)

### Color schemes

Set `BackgroundColor` or `Color`, and set `Theme` to match the background.

```cshtml {1} showLineNumbers
<Navbar BackgroundColor="BackgroundColor.Dark" Theme="NavbarTheme.Dark" Class="border-bottom border-body">
    <Brand>
        <NavbarBrand Href="/">Navbar</NavbarBrand>
    </Brand>
</Navbar>
```

[See demo here](https://demos.blazorbootstrap.com/navbar#color-schemes)

### Containers and placement

```cshtml {1} showLineNumbers
<Navbar BackgroundColor="BackgroundColor.BodyTertiary" Container="NavbarContainer.Default" Placement="NavbarPlacement.StickyTop">
    <Brand>
        <NavbarBrand Href="/">Navbar</NavbarBrand>
    </Brand>
</Navbar>
```

A fixed navbar leaves the page flow, so add padding to the `body` to keep content from going under it.

[See demo here](https://demos.blazorbootstrap.com/navbar#placement)

### Responsive behaviors

`ExpandBreakpoint` sets where the menu expands: `Never` keeps it collapsed, and `Always` never collapses it. `TogglerPosition="NavbarTogglerPosition.Start"` puts the toggler before the brand, and `BrandInCollapse="true"` hides the brand until the menu expands.

```cshtml {1} showLineNumbers
<Navbar BackgroundColor="BackgroundColor.BodyTertiary" TogglerPosition="NavbarTogglerPosition.Start">
    <Brand>
        <NavbarBrand Href="/">Navbar</NavbarBrand>
    </Brand>
    <ChildContent>
        <NavbarNav>
            <NavbarItem Href="/" Match="NavLinkMatch.All">Home</NavbarItem>
            <NavbarItem Href="/pricing">Pricing</NavbarItem>
        </NavbarNav>
    </ChildContent>
</Navbar>
```

[See demo here](https://demos.blazorbootstrap.com/navbar#responsive-behaviors)

### External content

Give a `Collapse` an `Id`, and set `ExternalCollapseId` to it. Set `ExpandBreakpoint="NavbarExpand.Never"` so the toggler shows at every width.

```cshtml {1,6} showLineNumbers
<Collapse Id="navbar-external-content" data-bs-theme="dark">
    <div class="bg-dark p-4">
        <h5 class="text-body-emphasis h4">Collapsed content</h5>
    </div>
</Collapse>
<Navbar BackgroundColor="BackgroundColor.Dark" Theme="NavbarTheme.Dark" ExpandBreakpoint="NavbarExpand.Never" ExternalCollapseId="navbar-external-content" />
```

[See demo here](https://demos.blazorbootstrap.com/navbar#external-content)

### Offcanvas

```cshtml {2-3} showLineNumbers
<Navbar BackgroundColor="BackgroundColor.BodyTertiary"
        CollapseMode="NavbarCollapseMode.Offcanvas"
        OffcanvasTitle="Menu">
    <Brand>
        <NavbarBrand Href="/">Navbar</NavbarBrand>
    </Brand>
    <ChildContent>
        <NavbarNav Class="justify-content-end flex-grow-1 pe-3">
            <NavbarItem Href="/" Match="NavLinkMatch.All">Home</NavbarItem>
            <NavbarItem Href="/pricing">Pricing</NavbarItem>
        </NavbarNav>
    </ChildContent>
</Navbar>
```

Above `ExpandBreakpoint` the menu shows inline. Use `NavbarExpand.Never` to keep the offcanvas at every width, and `OffcanvasPlacement` to choose the side it opens from.

[See demo here](https://demos.blazorbootstrap.com/navbar#offcanvas)
