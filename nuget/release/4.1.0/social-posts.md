```text
Blazor Bootstrap 4.1.0 is out 🎉

This release is about building complete apps, not just pages. It brings 11 new components, a better Grid, 11 sample websites, and .NET 11 support. It's free, open source and has no breaking API changes.

New components
Calendar with Month, Week, Day and Agenda views and drag to move and resize
Timeline, Mind Map and a read-only Table
Avatar, Rating Input, Navbar, List Group, Popover, Input Group and Button Group

Grid
A column chooser, CSV export and keyboard-accessible sorting

Showcase
11 complete sample websites built only with Blazor Bootstrap components: help desk, HR portal, banking, healthcare, e-commerce, learning, travel and more. Each has demo accounts and light and dark themes.

Also in 4.1.0
A .NET 11 build next to .NET 8, 9 and 10, new Breadcrumb and Preload service demos, accessibility improvements, and 14 bug fixes.

Get started:
dotnet add package Blazor.Bootstrap

Demos: https://demos.blazorbootstrap.com
Release notes: https://docs.blazorbootstrap.com/blog/blazorbootstrap-4.1.0
GitHub: https://github.com/vikramlearning/blazorbootstrap

Thanks to everyone who reported issues, sent pull requests and starred the project.
```
